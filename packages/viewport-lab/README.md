# Viewport Lab

A desktop app for checking one web page across several viewport sizes at once, each with its own controls.

## Requirements

- Bun

## Usage

From `packages/viewport-lab`, open the app with a page URL:

```bash
bun run start https://example.com
```

The URL must use `http://` or `https://`. Running `bun run start` without a URL opens an empty URL bar.
